# Tower Defense Academy — зручна навігація редактора (v6, тестове оновлення)

## Що змінено
- Замість сітки з 16 чисел для вибору уроку використовуй випадаючий список «Номер уроку» над назвою.
- Зліва з’являється список кроків із назвами та виділенням поточного.
- У центральній частині показується тільки один крок, тому не треба гортати всі блоки інших кроків.
- Є кнопки «Попередній крок» і «Наступний крок», додавання кроків, а після копіювання та перестановки вибір переходить на відповідний крок.
- Оригінальна логіка збереження, чернеток, імпорту, експорту та роботи з блоками залишається в editor.js.
- Поле «Короткий опис» приховано (input лишається для сумісності з editor.js).

## Установлення в GitHub (2 файли)
1. Обов’язково експортуй ZIP поточних уроків і збережи копію старого editor.html.
2. У репозиторії `deagorn/tower-defens` додай новий файл `editor-navigation.js` з архіву у корінь проєкту (Add file → Upload files).
3. Заміни **тільки** `editor.html` в корені репозиторію однойменним файлом з архіву. `editor.js` і `editor.css` НЕ змінюй.
4. Зроби Commit changes; перевір публікацію GitHub Pages; відкрий editor.html і натисни Ctrl + Shift + R.
5. Перевір переключення кроків, введення тексту, копіювання кроку, збереження чернетки й перегляд як учень.

## Важливо
Файли створені на основі публічної версії editor.html/editor.js, доступної в GitHub на 23.11.2026. Якщо в твоєму editor.html є ще НЕОПУБЛІКОВАНІ власні правки, повна заміна перезапише саме їх. Альтернатива: не міняти editor.html повністю, а додати перед `</head>` лише:
`<script defer src="editor-navigation.js"></script>`

Якщо після оновлення виникне проблема, видали цей рядок із editor.html або поверни попередній editor.html — усі дані уроків залишаться в Supabase.
