# Tower Defense Academy v5.5.1 — архівування + стиль пошуку

## Чому з’явилися помилки

1. `permission denied for table groups`: у Supabase були додані колонки `is_archived` і `archived_at`, але дозволи оновлення цих колонок не застосувалися (виконання лише ALTER TABLE замість всього upgrade-v5.3.sql).
2. Сірий рядок пошуку: CSS-правила для стандартних полів застосовувалися тільки до `.field input`, тоді як нове поле лежить всередині `.archive-search`.

## Встановлення

1. Зроби наявний експорт груп та уроків (за можливості).
2. Supabase → SQL Editor → New query. Запусти **тільки** `supabase/fix-archive-permissions-v5.5.1.sql`. Має повернути `can_archive = true` і `can_set_archive_date = true`.
3. Розпакуй цей ZIP у **нову папку**; відкрий її у VS Code і запусти Live Server. Не змішуй старий `online.css` та новий `index.html`.
4. Увійди як викладач, натисни «Архівувати групу», підтвердь, онови F5, перевір вкладку «Архів» і повернення групи до активних.
5. Учнівський вхід і доступ до раніше відкритих уроків не змінюються.

**Не запускай** заново `schema.sql` або всі SQL-оновлення з архіву. Це точковий патч.

Примітка: оновлення перевірене статично; потрібен тест на твоїй живій базі.
